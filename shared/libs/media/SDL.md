# SDL.md — gmbmedia vs SDL_image (SDL2_image) comparison

Document that collects the **results** of the comparison between the `gmbmedia` decoder
and **SDL_image** (which in turn uses libjpeg-turbo / libpng), and **how the tests were run**.
It serves to: (1) measure the decoding speed; (2) verify the **pixel-by-pixel
fidelity** against an external reference.

> Note: absolute numbers depend on the machine load (shared). Always refer
> to the **`sdl/gmb` ratio** measured in the **same** run, not to the absolute value.

---

## 1. Method

Three tools, all self-contained in `gmbmedia/tools/`:

| Tool | What it does |
|---|---|
| `tools/sdl_bench.c` | measures the speed: `mm_image_read`+`free` vs `IMG_Load`+`SDL_FreeSurface` |
| `tools/sdl_diff.c`  | compares the **pixels** (RGB channels): `pixel>8diff` + `maxdiff` |
| `test/run_tests.c` ("GOLDEN" section) | compares the decode with the **golden** generated by SDL (safety net in CI) |

### 1.1 Speed (`sdl_bench`)

- **Warmup** (1 unmeasured call), then **N iterations**.
- Timer: `clock_gettime(CLOCK_MONOTONIC)`; the **average time per
  decode** is reported in microseconds and the **`sdl/gmb` ratio**.
- Both read from file (`mm_image_read` vs `IMG_Load`).

```sh
# from the gmbmedia/ folder (with a freshly built out/libgmbmedia.a)
cc -O2 -Iinclude tools/sdl_bench.c out/libgmbmedia.a \
   -I/opt/homebrew/include/SDL2 -L/opt/homebrew/lib -lSDL2 -lSDL2_image -lm -ldl -o /tmp/sdl_bench
DYLD_LIBRARY_PATH=/opt/homebrew/lib /tmp/sdl_bench <file> 200
```

### 1.2 Fidelity (`sdl_diff`)

- Decodes the **same file** with gmbmedia and with SDL_image.
- For every pixel it compares the **R,G,B** channels; it reports the number of pixels with a
  difference **> 8** and the **maximum difference**.
- `maxdiff` **0–1** = faithful (rounding only); **≥ 8** = real divergence.

```sh
cc -O2 -Iinclude tools/sdl_diff.c out/libgmbmedia.a \
   -I/opt/homebrew/include/SDL2 -L/opt/homebrew/lib -lSDL2 -lSDL2_image -lm -ldl -o /tmp/sdl_diff
DYLD_LIBRARY_PATH=/opt/homebrew/lib /tmp/sdl_diff <file> [...]
```

### 1.3 Golden test (safety net, in `test/run_tests.c`)

In `test/fixtures/`:
- `golden420.jpg` — a JPEG fixture (4:2:0);
- `golden420.raw` — its **raw RGB decode generated by SDL_image** (the "truth").

The test decodes the fixture with gmbmedia and compares it with the golden: it must
match within `maxdiff <= 4`. **Verified**: by breaking the upsampling (going back to
"nearest") the test fails → such a regression is caught immediately.

## 2. Results (representative run)

Unit: µs per decode. `ratio = sdl/gmb` (>1 = gmbmedia faster).

| File | Formato | gmbmedia | SDL_image | ratio | maxdiff |
|---|---|---|---|---|---|
| `jpg1024.jpg` (1024²) | JPEG 4:2:0 | 1923 µs | 1285 µs | 0.67 | **1** |
| `big.jpg` (4000²) | JPEG 4:2:0 | 26627 µs | 18104 µs | 0.68 | **1** |
| `v444.jpg` (1024²) | JPEG 4:4:4 | 3437 µs | 2897 µs | **0.84** | **1** |
| `v422.jpg` (1024²) | JPEG 4:2:2 | 1168 µs | 744 µs | 0.64 | **1** |
| `sprite256.png` (256²) | PNG | 1086 µs | 651 µs | 0.60 | **0** |
| `sprite_rgb.png` (1024²) | PNG RGB | 16266 µs | 8215 µs | 0.51 | **0** |
| `sprite2048.png` (2048²) | PNG RGB | 46299 µs | 24351 µs | 0.53 | **0** |
| `rgba2048.png` (2048²) | PNG RGBA (alta entropia) | 96169 µs | 37966 µs | 0.39 | **0** |

### Reading

- **Fidelity**: JPEG **maxdiff 1**, PNG **maxdiff 0** → gmbmedia decodes **bit-faithfully**
  to the reference (rounding only). Caught by the golden test.
- **JPEG speed**: **0.65–0.85** of libjpeg-turbo's time (4:4:4 almost at parity).
  The residual gap is against a decoder with hand-written SIMD kernels;
  the optimizations applied (NEON islow IDCT, NEON dequant, NEON fancy upsampling,
  fast bit-reader, NEON color) reduced the initial gap (~24×).
- **PNG speed**: **0.39–0.60**. Gained with the **lookahead DEFLATE Huffman**
  (9-bit table; LSB-first bit order as per RFC1951) in `inflate` and with the
  8-bit output conversion via `memcpy` (it was a byte-per-byte loop). The residual
  bottleneck is the **Paeth** filter (≈92% of the rows in typical PNGs): it has an
  **intra-row dependency** (`a = d[x-fbpp]` uses the just-computed outputs). A
  **4-lane NEON** Paeth (one per channel, `a` = previous pixel) was tried:
  it is conceptually correct but in practice the chain is **latency-bound** and gives only
  **~4%** — it was **removed** (not worth the complexity/risk). The 1/2/4-bit
  support is present and correct (palette+gray).

## 3. Format coverage (gmbmedia)

`png, gif, jpg/jpeg, bmp, tga, tif/tiff, webp, ppm/pgm/pnm, qoi` (+ WAV audio).
WebP requires `libgmbwebp.dylib/.so` (bundle: `libs/webp/`, `Resources/libs/<rid>/`);
the loader walks up the CWD to find it.

## 4. Quick reproduction

```sh
cd gmbmedia
make all
# speed
cc -O2 -Iinclude tools/sdl_bench.c out/libgmbmedia.a -I/opt/homebrew/include/SDL2 -L/opt/homebrew/lib -lSDL2 -lSDL2_image -lm -ldl -o /tmp/sdl_bench
# fidelity
cc -O2 -Iinclude tools/sdl_diff.c  out/libgmbmedia.a -I/opt/homebrew/include/SDL2 -L/opt/homebrew/lib -lSDL2 -lSDL2_image -lm -ldl -o /tmp/sdl_diff
# golden (it is part of the suite)
./out/run_tests
```

SDL2/SDL2_image prerequisites: `/opt/homebrew` (only for the external tests; gmbmedia
does not link them).
