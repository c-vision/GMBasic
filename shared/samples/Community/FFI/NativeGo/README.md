# NativeGo — pure Go FFI (cgo) for GMBasic (c-abi, without `gmb_ffi.h`)

**Self-contained** Go module callable from BASIC via `DECLARE`. No GMBasic header required: only
`//export` + `-buildmode=c-shared`.

## Files

| File | Role |
|---|---|
| `math_go.go` | Go module: `math_add`, `math_scale`, `math_isprime`, `math_factorial`, `math_label`, `math_label_free` |
| `MathGo.bas` | BASIC program using `DECLARE FUNCTION ... LIB "./NativeGo/math_go"` |
| `build.sh` | `go build -buildmode=c-shared` → `libmath_go.dylib`/`.so` |

## Build & run

```bash
cd shared/samples/Community/FFI/NativeGo
sh build.sh        # -> libmath_go.dylib (+ libmath_go.h generated by cgo)
# then run MathGo.bas
```

## c-abi rules (Go limits)

- **Scalars**: `int64`/`float64` → BASIC `LONG`/`DOUBLE`, mapped directly.
- **OUT strings**: `C.CString` allocates on the **C heap**; GMBasic copies immediately, but the C
  buffer stays allocated → always expose a `*_free` (`math_label_free` via `C.free`).
- **IN strings**: `C.GoString` copies — never keep the `*C.char` after the call.
- **LIMIT**: Go **cannot** receive C structs **by value** in `//export` functions (pointers only).
  For the advanced types of `gmb_ffi.h` (`gmb_val_t`/`gmb_list_t`) Go is not suitable: use C/C++
  for `gmb-native`, Go only for `c-abi` scalars/strings.
- **Panic**: a `panic` inside an `//export` function is **not** containable (the Go runtime aborts)
  — handle errors internally and return sentinels.
