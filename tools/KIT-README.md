# C# tools of the monorepo (GMBasicSharp)

CLI harnesses and parity runners for the **C#** project (`IL`, `P-Code`, `VM/C` via native host).
All harnesses live in `GMBasicSharp/` and link the projects in `common/` and `Executor/`.

## Harness

| tool | usage |
|---|---|
| `test_ilrun` | `dotnet tools/runners/test_ilrun/bin/Debug/net10.0/test_ilrun.dll --engine=il <file.bas>` (also `--engine=pcode`/`vmc`) |
| `test_pcode` | `dotnet tools/runners/test_pcode/bin/Debug/net10.0/test_pcode.dll <file.bas>` |
| `test_vmrun` | `dotnet tools/runners/test_vmrun/bin/Debug/net10.0/test_vmrun.dll <file.bas> [timeout_s]` — VM/C with anti-stale of `gmb_vm_host` and browser/CDP cleanup |
| `test_astdump` | AST dump of a `.bas` |

Scripted input (interactive tests `@GET`/`READ`): `GMB_TUI_SCRIPT=$'a\rb\r'`.
Wrapper: `tools/sh/harness.sh <il|pcode|vmc|ast> <file.bas>` (sets
`GMBASIC_ROOT=../GMBasic` and `DYLD_LIBRARY_PATH` for the native libs).

## MiniTest parity (4 legs: IL, PCode, VM-C, C99Native)

```bash
tools/sh/test_minitests_parity.sh controls/       # targeted filter
tools/sh/test_minitests_parity.sh --all          # full suite (explicit)
tools/sh/test_minitests_parity.sh --interactive get_valid_parity.bas
```

Reads the MiniTests from `shared/minitests/`, uses `tests/GMBASIC.IlBackend.Tests` and the C
binaries in `GMBasic/native/gmb_vm_c/build`. `GMB_MINITEST_BUILD=1` forces the build of the test project.

## VM/C and interactive tests

`tools/sh/harness.sh vmc` uses `test_vmrun` (Conformance `vmtest` + anti-stale host). For
**interactive** tests (`@GET`/`READ`) the chunk generated by the C# compiler does not receive the
scripted input: use the native path (as in the C repo):
`tools/sh/gmb_c99native_run.sh` for C99, or `gmbchunk`+`gmb_vm_host` in
`GMBasic/native/...` (verified: `gv=ab`). The interactive tests are `TAG: interactive`.

## Notes

- The CWD is always the sample folder (no artifacts in the root).
- `GMBasicSharp/test_*` and `tools/` are **tools**: they are not part of the
  BASIC surface; the real tests live in `shared/minitests/`.
