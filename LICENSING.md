## Why the old split is gone

Until 2026-10-31 the tree carried an `Edition` axis: a `Commercial`/`Community` MSBuild property, a
`CommercialEditionRequiredException` for the database drivers, a `GMB_HAS_COMMERCIAL_DB` option, a
per-package `edition`/`requiresCommercial` gate, and two sample roots
(`shared/samples/Commercial`, `shared/samples/Community`). That axis existed to sell a separate
edition. It has been **removed at every level** — build matrix, runtime service, native option,
package manifests, samples, scripts and docs: **one build, one set of samples, one license**, and
every function (including the file databases: DBF, ISAM, SPEED, Ledger) is available to everybody.
The samples now live directly under `shared/samples/<Category>/` (the old `Community/` level is
gone too, so no folder name refers to an edition).

The folder [`GMBasic/gmbllm/`](GMBasic/gmbllm/README.md) (model compiler: quantization encode,
training, converter) stays **separate for technical reasons** — it is the part that produces or
alters model weights — but it is **not** a different license: it is PUL like the rest.

## Le librerie di `shared/libs/` sono **nostre**

Tutto `shared/libs/<nome>/` è codice nostro e ricade nella **PUL** come il resto del repository
(sorgenti + `.inc` esportati + header pubblici). Due eccezioni dichiarate:

- `shared/libs/ffi/` è la copia vendorizzata di **libffi** (MIT, vedi sopra);
- `shared/libs/graphics/VENDOR.md` documenta quali sorgenti provengono dalla suite `gmbsuite`
  (anch'essi nostri, stessa licenza): è una nota di **provenienza**, non una licenza diversa.

## Cosa **non** è in questo repository

- **`GMBasicIDE/`** (IDE GUI nativa) è **fuori dal repo** (`.gitignore`, riga commentata): è in
  sviluppo e contiene materiale di terzi con licenza propria —
  `resources/icons/LICENSE-AvaloniaVisualBasic6.txt` e `resources/icons/NOTICE.txt` (set di icone
  stile VB6). Se un giorno entrasse in un bundle o in una release, quei file vanno distribuiti con
  la loro licenza e il loro NOTICE.
- il manuale per KDP è locale e git-ignored, non fa parte della distribuzione del software.

The dependency direction is one-way: **this repo → LLMEnv**. The Apache code of the engine stays
Apache even when linked from PUL code; the reverse (Apache code depending on PUL code) is forbidden,
and `LLMEnv/tools/gmb_license_gate.py` must exit 0 after any change on the LLM boundary.
